# Spec Delta

## Purpose

Навигация по структуре репозитория и чтение содержимого файлов на любых ветках, тегах или коммитах.

## ADDED Requirements

### Requirement: Чтение содержимого файла
Сервер ДОЛЖЕН предоставлять инструмент `gitlab_read_file`, позволяющий получить текстовое содержимое файла по указанному пути `file_path` на заданной ветке, теге или коммите (параметр `ref`).

#### Scenario: Успешное чтение существующего файла
- **WHEN** агент запрашивает файл `gitlab_read_file(file_path="src/config.ts", ref="main")`
- **THEN** сервер возвращает декодированное текстовое содержимое файла

#### Scenario: Чтение несуществующего файла
- **WHEN** агент запрашивает несуществующий файл `gitlab_read_file(file_path="missing.txt")`
- **THEN** сервер возвращает понятное сообщение об ошибке с информацией о том, что файл не найден по указанному пути на выбранном ref

### Requirement: Просмотр дерева файлов репозитория
Сервер ДОЛЖЕН предоставлять инструмент `gitlab_list_tree`, возвращающий список файлов и директорий по указанному пути в репозитории на заданном `ref`, с возможностью рекурсивного обхода.

#### Scenario: Получение списка файлов корневой директории
- **WHEN** агент вызывает `gitlab_list_tree(ref="main", path="")`
- **THEN** сервер возвращает список элементов (файлов и папок) корня репозитория с указанием типа (`blob`, `tree`), имени и пути

#### Scenario: Рекурсивный просмотр структуры поддиректории
- **WHEN** агент вызывает `gitlab_list_tree(ref="develop", path="src", recursive=true)`
- **THEN** сервер возвращает полный иерархический список всех вложенных файлов и папок внутри каталога `src`
