# Spec Delta

## Purpose

Управление запуском и поведением MCP-сервера через многоуровневую систему конфигурации с поддержкой CLI-флагов, переменных окружения и .env файлов, а также фильтрация доступных инструментов.

## ADDED Requirements

### Requirement: Многоуровневая загрузка параметров конфигурации
Сервер ДОЛЖЕН загружать конфигурационные параметры с соблюдением строгого приоритета: CLI-аргументы имеют наивысший приоритет, далее следуют переменные окружения процесса, затем значения из файла .env, и в последнюю очередь значения по умолчанию.

#### Scenario: Переопределение значения из .env через CLI флаг
- **WHEN** в файле .env указан параметр `GITLAB_API_URL=https://gitlab.example.com/api/v4`, а сервер запущен с флагом `--url https://gitlab.custom.com/api/v4`
- **THEN** сервер использует URL `https://gitlab.custom.com/api/v4`

#### Scenario: Указание кастомного пути к .env файлу
- **WHEN** сервер запускается с аргументом `--env-file /path/to/custom.env`
- **THEN** сервер считывает переменные окружения из указанного файла вместо дефолтного `.env`

#### Scenario: Отсутствие обязательного токена доступа
- **WHEN** токен GitLab не передан ни через флаг `--token`, ни через `GITLAB_TOKEN`, ни через файл .env
- **THEN** сервер завершает работу с ненулевым кодом и выводит понятную ошибку в stderr

### Requirement: Модульная фильтрация доступных инструментов
Сервер ДОЛЖЕН регистрировать в MCP протоколе только те группы инструментов, которые указаны в параметре `tools`. Поддерживаются модули `mr`, `repository`, `ci`, `settings`, а также псевдоним `all`.

#### Scenario: Запуск с ограниченным набором инструментов
- **WHEN** сервер запущен с аргументом `--tools mr,repository`
- **THEN** в списке инструментов MCP регистрируются только инструменты для работы с Merge Requests и файлами репозитория, а инструменты модулей `ci` и `settings` отсутствуют

#### Scenario: Запуск со всеми инструментами по умолчанию
- **WHEN** параметр `tools` не передан явно
- **THEN** сервер регистрирует инструменты модулей `mr`, `repository`, `ci`, `settings` (эквивалентно `all`)
